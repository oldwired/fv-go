# fv-go - Free Vision for Go

This project is a port of Free Vision to Go.
It aims to provide a similar functionality and API as Free Vision, but written in Go.

Free Vision originally was Free Pascals version of the Turbo Vision console UI framework.

This is a port of the modernized Delphi version of Free Vision. https://github.com/oldwired/fv-delphi-modern

The Delphi code as Reference is in the fv-delphi folder.
